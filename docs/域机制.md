## 认证授权域

### 是什么

基于 Sa-Token + Redis 的登录会话与 RBAC 鉴权最小闭环：登录/登出/会话校验、`@SaCheckPermission`/`@SaCheckRole` 注解鉴权、双服务共享会话。

### 判定边界

- 账号可登录 = `t_sys_user.status=1` 且 `deleted=0` 且 BCrypt 口令匹配；失败提示统一「用户名或密码错误」（不区分不存在/错密）。
- 会话存 Redis（Sa-Token Redisson），user-service 与 system-service 共享同一 Redis 即可互认 token。
- 权限标识以 `t_sys_role_permission.permission` 为准（status=1）；`t_sys_permission` 仅作注册表种子。
- 角色标识 = `t_sys_role.role_name`（DDL 无独立 code 字段）。

### 状态流转与数据流

1. `POST /api/auth/login` → 校验账号 → `StpUtil.login(userId)` → 返回 token（Header `Authorization: Bearer`）。
2. 业务接口 → `SaInterceptor` 登录校验（排除 `amao.satoken.exclude-paths`）→ 注解读 `StpInterface`。
3. 权限读取两条路径：
   - user-service：Mapper 联查本地表（`user_role ⨝ role` / `user_role ⨝ role ⨝ role_permission`）；
   - system-service：`UserPermFacade` → Feign 直连 `GET /api/rpc/user/perm/{userId}`（适配器在 boot；失败返回空权限，鉴权拒绝而非 500）。

### 不可违背的业务规则

- 密码字段禁止明文出层、禁止写日志；登录响应不得携带 password。
- `/api/rpc/**` 本期无内部签名（ADR-0001 / 架构规范 §3），不得扩大到其它路径。
- 鉴权失败统一 HTTP 200 + `Result.code` 401/403。

## 系统域

### 是什么

系统域承载跨业务的平台级机制：基于 RBAC 的权限管理，以及 key/value 两段式字典体系。表模型见 `doc/DDL.sql`。

### 判定边界

- RBAC：用户（`t_sys_user`）— 用户角色关联（`t_sys_user_role`）— 角色（`t_sys_role`）— 角色权限关联（`t_sys_role_permission`）— 权限（`t_sys_permission`，type 1:菜单 2:按钮 3:接口，parent_id 支持树形）。权限判定 = 关联表命中且 status=1；关联行是"状态性信号"，禁止当作事件证据（架构规范 §4.3）。
- 字典：`t_sys_dict_key`（dict_key 唯一）挂 `t_sys_dict_value`（(dict_key, value) 联合唯一）；字典值判定只以字典表为权威，禁止硬编码枚举绕开。

### 状态流转与数据流

业务实现铺开后回填（当前仅表模型，无 Service/Controller）。

### 不可违背的业务规则

- 权限标识 `permission` 全局唯一；同一 (user_id, role_id)、(role_id, permission) 联合唯一，禁止重复授权记录。
- RBAC 四表（role/user_role/role_permission/permission）已补齐 BaseModel 审计字段（2026-09-23）；`t_sys_role.role_name` 兼角色标识。

## 用户域

### 是什么

系统用户与账号生命周期管理，落 `t_sys_user`（username/phone/email 三唯一键）。

### 判定边界

- 账号可用 = `status=1` 且 `deleted=0`；禁用（status=0）是**保留数据的停用**，删除走逻辑删除（deleted=1），禁止物理删除。
- `deleted` 逻辑删除下，username/phone/email 唯一索引仍被"已删除"行占用——同名重建账号属敏感操作，须按唯一键冲突处理，禁止直接插入。

### 状态流转与数据流

业务实现铺开后回填（当前仅表模型，无 Service/Controller）。

### 不可违背的业务规则

- 密码字段禁止明文出层、禁止写日志（配置与接口参考登记接口时须注明）。
- status/deleted 两字段语义独立：禁用 ≠ 已删除，判定时必须同时校验两个字段。
