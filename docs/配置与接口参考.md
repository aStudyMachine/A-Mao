# 配置与接口参考

> **定位**：配置字段与对外接口契约的唯一权威。其他文档引用本文，禁止转抄字段定义。
> 维护铁律：字段/接口**只增不减**（见架构规范 §5）。废弃字段**保留登记行**并标记状态，禁止删除行——删行的代价是旧配置反序列化崩溃、用户配置整体丢失。
> 最后更新：2026-09-24 | 当前版本：1.0-SNAPSHOT

## 1. 配置字段

| 字段 | 类型 | 默认值 | 说明 | 引入版本 | 状态 |
|------|------|--------|------|----------|------|
| `sa-token.token-name` | string | `Authorization` | 令牌 Header 名 | 1.0-SNAPSHOT | 生效 |
| `sa-token.token-prefix` | string | `Bearer` | Header 令牌前缀 | 1.0-SNAPSHOT | 生效 |
| `sa-token.is-read-cookie` | boolean | `false` | 不读 Cookie | 1.0-SNAPSHOT | 生效 |
| `sa-token.is-read-header` | boolean | `true` | 从 Header 读令牌 | 1.0-SNAPSHOT | 生效 |
| `sa-token.is-concurrent` | boolean | `true` | 允许同一账号多处登录 | 1.0-SNAPSHOT | 生效 |
| `sa-token.is-share` | boolean | `false` | 多端登录不共享 token | 1.0-SNAPSHOT | 生效 |
| `sa-token.token-style` | string | `uuid` | 令牌风格 | 1.0-SNAPSHOT | 生效 |
| `sa-token.timeout` | long | `604800` | token 有效期（秒，7 天） | 1.0-SNAPSHOT | 生效 |
| `sa-token.active-timeout` | long | `-1` | 无操作超时；-1 关闭 | 1.0-SNAPSHOT | 生效 |
| `sa-token.is-log` | boolean | `false` | 关闭 Sa-Token 日志 | 1.0-SNAPSHOT | 生效 |
| `amao.satoken.exclude-paths` | list | `/api/auth/login`,`/api/rpc/**` | 登录校验排除路径（Ant） | 1.0-SNAPSHOT | 生效 |
| `spring.cloud.nacos.server-addr` | string | `127.0.0.1:18848` | Nacos 注册/配置中心地址（gRPC = 端口 + 1000） | 1.0-SNAPSHOT | 生效 |

登记规则：

- **对外契约**字段只增；改名/删除禁止；语义扩展时字段名与默认值不变。
- **配置字段**确认废弃且全仓无任何引用后可删除，须同步移除本表条目并在提交说明中注明（架构规范 §5）。
- 新增开关默认取**安全侧**（不启用危险行为）。
- 用户可即时修改的配置在**修改发生时即时持久化**，不依赖手动"保存"。
- 任何切换"当前方案/当前上下文"的入口必须同步全部关联状态（架构规范 §5）。

## 2. 对外接口契约

端点一律 `POST` + 动词开头 camelCase 路径，入参走请求体（架构规范 §6）。

| 端点 | 方法 | 请求要点 | 响应要点 | 引入版本 | 状态 |
|------|------|----------|----------|----------|------|
| `/api/auth/login` | POST | `{username,password}`（BCrypt 校验；密码禁止日志） | `Result<{tokenName,tokenValue}>` | 1.0-SNAPSHOT | 生效 |
| `/api/auth/logout` | POST | Header `Authorization: Bearer <token>` | `Result<Void>` | 1.0-SNAPSHOT | 生效 |
| `/api/auth/getUserInfo` | POST | 需登录，无请求体 | `Result<{id,username,realName}>`（无密码） | 1.0-SNAPSHOT | 生效 |
| `/api/rpc/user/getUserPerm` | POST | **内部 RPC**，body `{userId}`，本期放行无签名（ADR-0001） | `Result<{userId,roles,permissions}>` | 1.0-SNAPSHOT | 生效 |
| `/api/dict/listDictValues` | POST | 需权限 `sys:dict:list`，body `{dictKey}` | `Result<List<{id,dictKey,value}>>` | 1.0-SNAPSHOT | 生效 |
| `/api/auth/user-info` | GET | 需登录 | `Result<{id,username,realName}>`（无密码） | 1.0-SNAPSHOT | 废弃（更名 `/api/auth/getUserInfo`） |
| `/api/rpc/user/perm/{userId}` | GET | **内部 RPC**，路径变量 `userId`，本期放行无签名（ADR-0001） | `Result<{userId,roles,permissions}>` | 1.0-SNAPSHOT | 废弃（更名 `/api/rpc/user/getUserPerm`） |
| `/api/dict/{dictKey}` | GET | 需权限 `sys:dict:list`，路径变量 `dictKey` | `Result<List<{id,dictKey,value}>>` | 1.0-SNAPSHOT | 废弃（更名 `/api/dict/listDictValues`） |

鉴权失败约定：HTTP 200 + `Result.code`：401 未登录、403 无权限（`UN_AUTHORIZED`/`REQ_REJECT`）。

登记规则：

- 端点一律 `POST`，路径末段为动词开头 camelCase，入参走请求体；禁止路径变量与 query 传参（架构规范 §6）。
- 响应统一包装 `Result<T>`（code/data/message），响应字段只增不删不改名；禁止裸 Map/裸实体出 Controller 层。
- 破坏性变更必须版本化（`/v1` → `/v2`），旧版本按承诺期保留。
- 前后端共享的枚举/状态码/DTO 由 OpenAPI 契约单一生成，两侧禁止各手写一份（架构规范 §4.1；前端建立后生效）。
- 写接口必须声明幂等策略（幂等键/去重规则），术语见 `CONTEXT.md`。
